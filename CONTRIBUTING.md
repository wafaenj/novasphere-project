Contribution au projet

Afin de travailler efficacement en équipe, nous avons défini quelques règles simples :

Chaque membre travaille sur sa propre branche
Les modifications importantes passent par une Pull Request
Les commits doivent avoir un message clair
Aucun secret ne doit être stocké dans le dépôt GitHub
Chaque membre est responsable de sa partie du projet
Les tests doivent être réalisés avant de fusionner les changements
L'objectif est de garder un projet propre, compréhensible et facilement maintenable par l'ensemble de l'équipe
